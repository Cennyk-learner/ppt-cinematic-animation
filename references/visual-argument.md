# 把讲者的判断变成观众看得见的变化

给数据、机理和对照选动画时，先找一个能随论点变化的量。从原资料取数，把示意、测量和外推分别标清。

## 写出一拍

在分镜里写下“谁保持原位 → 哪个量如何变化 → 停在哪里给观众看”。例如，两个轮子的外形可以极简，大小轮在同一段时间里准确转过一圈和两圈，就能表达两倍转速。需要估数时，把单位放到对象附近，把结论放在稳定、安静的画面区域。

| 演讲要解释什么 | 镜头怎么做 | 现场如何检查 |
|---|---|---|
| 数量超过原画面 | 让原刻度、曲线或材料延伸到画外，给相机一个能追随的对象 | 回到旧视点，还能认出原来的单位与起点 |
| 只改一个条件 | 前后锁定机位、物件、比例和光，只改变讨论中的因素 | 把两个终态来回切，观众能指出哪里不同 |
| 观众刚学会一个规则 | 后面把同一物件或动作带回来，让它回答另一个问题 | 试着删去解释性小字，回扣仍看得明白 |

把讲述时间留在结果上。前景出现的细微改变本身就是信息时，其他动作可以停下。删掉某段文字后会读错单位、条件、来源或结论，就把它留下。

## 选择制作方式

原生文本、线、旋转、路径或 Morph 能讲清楚，就在 PowerPoint 里完成。需要连续的遮挡、折叠、自阴影或明显的相机透视时，用 Three.js、Blender 或能按参数出帧的渲染器做无字画面。锁住随机种子、相机和光，给关键时刻明确的时间或参数。保留原始渲染场景，后续可重新出图。

| 在哪一刻启动 | 怎样放进 PPTX |
|---|---|
| 讲者翻到这一页即开演 | 把当前段出成一次播放的动图，最后一帧设计成可长期停留的构图。下一个要独立起播的连续镜头另起一页。 |
| 要等本页内的下一次点击 | 两三个状态分别放图片，用原生出现、擦除或淡入来切。持续运动需要从零开始时，改成独立进页。 |
| 需要观众自由拖动 | PPT 用几个离散状态现场比较。要保留连续拖动时，交付形式需支持网页交互。 |

若渲染器已输出一组不透明、等尺寸的连续 PNG 或 JPEG，可以直接打包。帧名以数字结尾，例如 `frame_000.png`、`frame_001.png`，一段动作一个目录。

```bash
python scripts/pack_scene_frames.py frames/ fold.gif --fps 20
```

默认只播放一次。只有从任意一帧开始都讲得通的循环氛围才加 `--loop`。已有浮点 BGR 帧的工程继续使用 `render_tools.gif(..., loop=-1)`。把成片当作普通图片插入，主标题、来源、数值和可编辑的图解另放原生层。用放映模式检查首帧、动作中点、终态、翻页和重新进页，确认 GIF 调色后细线和标题从头到尾都可读。

参考作品 [The Last Boring Slide](https://claude.ai/artifact/Cy2d8Vn63CnzCtonA1LSah#tower-3)。学习其中变化量、参照与回扣的关系，为新题目设计自己的物件和镜头。
