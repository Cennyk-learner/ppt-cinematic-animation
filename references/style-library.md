# 手法库：做过并留下来的画面

这里记的是在真实的答辩、路演、课堂 PPT 里做出来、被看过的动画手法，以及参考了什么、适合讲什么、怎么做、反响如何。

**怎么用这份库。** 它是资产，不是模板。新题目先从内容出发自己想（方法见 `ideation.md`），想完再回来对照三件事：有没有现成的做法可以省力；这一招在同一份稿里是不是已经用过（用过就换，防止审美疲劳）；类似的东西以前有没有被否过、为什么。

每条的格式：画面 → 参考 → 适合讲什么 → 做法 → 反响。做法里提到的函数见 `pipeline.md`，带括号的是 `ppt_tools.ps1` / `render_tools.py` 里的函数名。

## 1. 开场与转场

**一张全景，光束巡扫，照到哪里哪里的字亮起**
- 画面：一张宽幅夜景里放几处小场景，对应这一页要讲的几件事。光束从画外打进来，按顺序扫过每一处；每处旁边有一组书法大字，平时暗灰，被照到才亮，光走了又暗下去。
- 参考：游戏里"视野扫到哪里就加载哪里"；搜救探照灯；灯塔。
- 适合讲：一页有并列的几个问题或几个方案，需要一个把它们拢在一起的开场。
- 做法：整段烧成一个循环动图，因为它是进页第一幕。光斑轨迹用关键帧（`track`），光柱用 `beam_cone`，暗片和亮片按光照蒙版混合（`light_reveal`），字用 `text_mask` 画成蒙版、按光斑到字的距离决定亮度（`lit_text`）。几组字大小、角度各不相同，一横一竖一横，贴着各自的场景。问题页用冷光，方案页用暖光，两页结构对应、色调相反。完整可跑的例子见 `examples/lighthouse/`。
- 反响：很受认可。和内容无关的开场（光扫一座和后文无关的山）会被批评"关联度不强"。

**雾转场**
- 画面：一团雾从左向右漫过画面，雾过之后是下一幕。
- 做法：一张带透明度的雾 PNG 走原生路径（`FogCut`），下一幕的图在雾经过时淡入，上一幕的层退场（`Retire`）。雾可以过程生成（`make_fog`），也可以让生图工具画一张"黑底尘云"再转透明度，质感更好。
- 反响：一直留着。跨页时用不了，改用翻页淡入或平滑切换。

**聚光、拉开、回到原页**
- 画面：三栏并列的原页。点一下，本栏以外压暗；再点一下，本栏的竖条向两侧拉开成整幅场景，几拍演完自动合回三栏。
- 适合讲：原页已经是"三个并列要点"的版式，每个要点背后有一段过程。
- 做法（一栏两次点击）：
  - 第 1 下：另外两栏盖 70% 的黑（0.5 秒淡入），本栏叠一层很淡的中心提亮。
  - 第 2 下：本栏位置换成整幅场景的第一个状态，另外两栏盖上不透明黑幕；黑幕向两侧滑走（0.3–1.2 秒），场景从竖条展开成整幅，标题副本滑到新位置。然后每 1.5 秒一个状态（下一状态淡入 0.8 秒，短词淡入、上一个短词淡出）；"先静"一拍（画面压暗）；"后爆"一拍（一次性大动作，见第 3 节"前后状态"）；余波停一拍；最后场景淡出、其余图层直接消失，回到三栏。
  - 图层顺序自下而上：原页 → 聚光压暗层 → 每栏的场景栈 → 拉开用的黑幕 → 原页标题 → 移动的标题 → 短词和引线。
- 反响：是最早定下"全部做在一页里、转场用原生动画"这条路子的一页。

**重来一遍**
- 画面：一段过程先按"别人的做法"走一遍，画面平静地回到起点，再按"我们的做法"走一遍，结果不同。
- 参考：《罗拉快跑》的三次重来；《萨利机长》听证会上的模拟回放。
- 适合讲：同样的条件下，做法不同导致结果不同。
- 做法：第二遍用同一组底图的副本叠在上面淡入，第一遍的线和字退场。回到起点用一秒的叠化，不要快倒的闪烁。

**收紧：一大团收成精确的轮廓**
- 画面：一团覆盖全画面的模糊色块，缩小并落到真实地形上的某一处，变成边界清楚的范围。
- 参考：台风路径图上越远越宽的不确定性圆锥。
- 适合讲：粗放和精确的差别。
- 做法：色块是一张径向渐变 PNG，中心对准目标位置，原生缩放收到约四分之一（`ScaleTo`），同时淡出，让精确轮廓淡入。

**图上的线接到真实的光**
- 画面：方案图上的金色路线淡出，一条形状和下一张照片里山路车灯重合的金线淡入，然后底图换成那张照片，金线再淡出，只剩真实的车灯。
- 参考：匹配剪辑，《2001 太空漫游》的骨头接飞船。
- 适合讲：方案落地、计划变成现实。
- 做法：在下一张图上按网格读出路的折线（`grid_view` + `pct`），画成发光线图层，压在那张图上面淡出。

**逐级拉远**
- 画面：从一个现场出发，镜头一级一级拉远到县、市、省、全国（或街道、城市、大洲），每一级汇聚的连线亮起，角上的层级名跟着换。
- 参考：《十的次方》那种逐级变尺度的短片。
- 适合讲：层级贯通、数据汇聚、影响范围。
- 做法：每一级是一张真实影像（航拍、高空俯拍、夜光遥感），下一级从放大状态缩回满幅，上一级同时淡出（`ZoomOut`）。地图必须用真实影像。

## 2. 用光讲事

**唯一的光源**
- 画面：几乎全黑的场景里只有一个光源（头灯、状态灯、灯塔、台灯），它照到的东西就是这一拍要看的东西。
- 做法：让生图工具出"不亮"和"亮"两张同构图，循环动图里在两张之间做明暗脉动（`blink`、`pool`）。

**光从一侧照进来**
- 画面：画面先是全暗的，一块软边的暗层从左往右退开，像窗外的光照进来，受光的地方一处处被引线点出来。
- 适合讲：光线、方向、"注意力该落在哪里"。
- 做法：一张满幅的黑色矩形加大半径柔边，原生直线路径向右移出画面（线性速度），走完后直接退场。

**一盏一盏亮起，一段一段熄灭**
- 画面：满坡的灯依次亮起；或者档案室过道里的灯从近到远一格格亮到底、从远到近一段段熄灭。
- 适合讲：覆盖、延续、中断。
- 做法：亮和灭各一张同构图。按灯的位置（`light_points` 从两张图的差里自动找）或按透视里的嵌套矩形切成若干透明图层，原生淡入错开零点几秒。

**先乱闪，再各自稳定**
- 画面：满坡的灯起初杂乱地闪，然后各自落到自己的节拍上。
- 适合讲：试错、迭代、收敛。
- 做法：两个动图，一个每盏灯随机相位快闪，一个各自慢闪，中间叠化。

**雨幕扫过，灯换了颜色**
- 画面：一道雨帘从左扫到右，扫过的地方灯从绿变成琥珀色。
- 适合讲：状态切换、等级变化。
- 做法：雨帘是一张透明 PNG 走直线路径，新状态的动图用同方向、同速度的擦除跟在后面。

## 3. 用时间讲事

**同一个机位，很多年**
- 画面：固定机位，同一个地方经历夏夜的雨、秋天、雪夜、春天的清晨；那里的设备换了一代又一代，地上的痕迹一点点变化。画面上方一条记录线随时间画出来。
- 参考：《少年时代》十二年拍一部；《诺丁山》里一路走过四季的长镜头；定点摄影。
- 适合讲：长期积累、历史数据的价值、一代代更替。
- 做法：先出一张基准图，后几张都是上一张的编辑（"同一地点同一机位，几年以后，季节变了"），构图几乎不漂。每季一个带天气的循环动图，原生叠化。
- 反响：好用，对方会主动要求保留。

**夜到晨**
- 画面：同一机位，风暴夜到第二天清晨，光从人造的灯换成太阳。
- 做法：同一张阴天底片分别编辑出夜景和清晨，两个循环动图之间用雾转场或叠化。见 `examples/lighthouse/`。

**前后状态：完整的 → 一次性的大动作 → 之后的样子**
- 画面：完整的坡面（建筑、冰架、堤坝……），下一拍崩落的部分沿坡滑下，尘云翻起，露出之后的样子。
- 做法：前、后两张同构图加一张纯色分割蒙版。前图乘蒙版得到会动的那块透明图层（`slide_mask`），走路径并淡出；后图垫在下面。尘云用黑底图转透明度，几团依次翻起、放大、淡出。镜头可以同时轻微后拉（满幅层从 106% 缩回 100%）。
- 反响：对方要的往往是"再足一点、再夸张一点"，特效不够时加浓烟和尘幕，但不要用震动和闪白。

**痕迹逐级扩大**
- 画面：同一个镜头里，裂缝从一指宽到一掌宽再到错台；锈迹、水位、积雪同理。
- 做法：一串同构编辑图，叠化。

## 4. 对照

**分屏：同一条标准套在两个场景上**
- 画面：左右两半各一个场景，各有一条曲线，同一条虚线阈值横穿。左边越线了、什么都没发生；右边没越线、出事了。
- 适合讲：一条死板的标准为什么两头都错。
- 做法：两半各取原图中间一半。阈值线左右各画一段，停在标签前面，不压字。角上用小签标"误判""漏判"（`Tag`）。

**同一个问题，两种回答**
- 画面：先是一份只有一句套话的通报，再是一份逐项列出范围、对象、责任、时限的报告。
- 三种落地方式：会议室大屏上先后显示；桌面上两张纸并排；航拍图上"一大团"对"精确范围加路线"。

**断开的线和连着的线**
- 画面：同一段时间轴上，别人的记录每到交接处就断开、归零重画，旧的一段变成灰色虚线；我们的是一条连续的金线，交接处只有一个小圆点。
- 参考：Tufte 的小型趋势线。
- 做法：每一段是一张裁好的透明 PNG（`wrgba`），原生自左向右擦除；断点是红色虚线。

**消息走到半路停下**
- 画面：近处一个小站，远处山脊上一个大站，中间隔着山谷。光点从小站出发，走到半路变暗、停住，中间一个红色的不等号。
- 适合讲：接口不通、标准不一。
- 做法：光点沿折线走（`PathAlong`）到一半淡出。

**云海上的孤峰**
- 画面：云海里露出几座高低不同的山峰，每座峰顶一个亮灯的小站。连线逐段亮起又断开，各自的光到不了别的峰。
- 适合讲：层级不通、信息孤岛。
- 做法：峰顶位置从"亮灯图减灭灯图"里自动找（`light_points`），标签跟着位置走。

## 5. 屏幕、文件和房间

**越肩看大屏**
- 画面：人的背影占左下，一块大屏占画面中右，屏上的曲线是主体。
- 做法：让生图工具直接把简单的曲线画在屏上（一条乱线、几条干净的分量），前后两张是编辑关系，用擦除切换。
- 反响：屏不够大的版本会被说"没有突出要点"。

**一群人在会议室看大屏，屏上是真的在跑的系统**
- 画面：前排是几个人的后脑勺和肩膀，剪影压在屏幕下沿；屏上是真实系统界面的运行过程，弹出提示、点按钮、几步流程依次打勾、结果出来、往下翻。
- 参考：《萨利机长》《阿波罗 13 号》里的指挥大厅；单场景戏。
- 做法：见 `pipeline.md` 的"把真实界面放进实景屏幕"。界面用浅色原版、界面内部不做运镜、每个状态一张图层按顺序切、重要内容放在屏幕上部八成。
- 反响：效果最"真"的一种。深色主题加界面内推近的版本被否；界面浮在画面上挡住人头被说"太假了"。

**台灯下的桌面和一份文件**
- 画面：正俯拍的深色桌面，台灯的暖光，边角有档案袋、印泥和印章，中间空着，一张纸滑进来落定。
- 参考：调查类电影里的文件特写；俯拍平铺的静物摄影。
- 适合讲：授权、资质、证据、合同。
- 做法：正俯拍是关键，扫描件放上去透视才对。纸是一张带投影、转两三度的图片（`Paper`），先放占位图，之后用"更改图片"换成真件，位置和动画会保留。

**三张纸：通用回答、红笔改过的稿、填满的报告**
- 画面：桌面上依次滑进三张纸，第二张上红笔的波浪线、圈、删改一处处出现，第三张一行一行填满。
- 参考：《天才捕手》里编辑的红铅笔；报纸校样。
- 做法：纸用 PIL 画，字是清楚的。同一张纸出"多写一行"的若干版，叠在同一位置用自左向右的擦除依次露出。
- 代价：字多，要凑近看。

**档案室的一点透视**
- 画面：两排档案架向正中的灭点退去，越往里年份越早。一段架子熄灯、盒子没了，只剩灰尘里的方印。
- 参考：《黑水》里按年份排文件的戏；失窃后一直挂着的空画框；库布里克式的一点透视。
- 适合讲：记录的丢失和保全。
- 代价：安静，气势弱。

**航拍图上画方案**
- 画面：一张真实的航拍夜景，影响范围、沿真实道路的路线、集合点、关卡依次画上去，路线上有光点流动。
- 参考：劫案片的计划推演，战争片的作战地图。
- 做法：先给底图打网格读坐标（`grid_view`），再画多边形、路线、标记；光点是原生小圆点沿折线路径重复走（`PathAlong` 带重复次数）。

**镜头推向画面里的一点**
- 画面：满幅的场景缓缓推近到某个细节（一盏灯、一块屏、一个人），焦点在画面里不动。
- 做法：`PushIn`（原生缩放 + 同步位移）。只对满幅的层做，叠在上面的小图层会相对滑动。

## 6. 推近与细节（平滑切换）

平滑切换（Morph）适合"同一张画面从全景推到细节"这类跨页的镜头运动，规则见 `pitfalls.md`。

**从展厅推进画里**
- 画面：一张展厅照片里挂着这幅画，切到下一页时照片放大、画框位置对准，画面变成画本身，展厅淡出。
- 做法：两页放同名的图（名字以 `!!` 开头），第二页把它放大到满幅；照片在第二页做淡出。

**推近到细节，叠化成实物**
- 画面：推近到画里的一块颜色，叠化成这种颜料的原料静物（原石、研钵、颜料粉）。
- 适合讲：材料、成本、工艺。
- 做法：平滑切换推近，再在同一页叠化到一张实拍质感的静物图。

**极近特写 + 引线标注**
- 画面：推到看得见笔触和裂纹的极近特写，几根细引线标出"这一笔是什么"。
- 做法：引线是一张透明线图层，擦除画出；圈用细圆环淡入；标签小字。

**作品墙：铺满，再只留一个**
- 画面：几十张作品错落着一张张淡入，铺满一面；然后全部压暗，只留要讲的那一张。
- 适合讲：数量、全貌、"在所有这些里，它是哪一个"。
- 做法：每张图错开 0.04–0.05 秒淡入；压暗层淡入，同时把要留的那张复制一份压在暗层上面。

**旧地图叠化成风景**
- 画面：一张老地图缓缓推近，叠化成同一地方的风景画或实景照片。
- 做法：地图缓推（`AddGrow`），风景图在推近末段淡入并继续缓推，节奏衔接上。

**扫描线扫过**
- 画面：一根细的竖亮线从左扫到右，扫过之后画面的某一层信息被揭示出来。
- 适合讲：检测、研究、"我们看到了肉眼看不到的东西"。

## 7. 图表与文字

**底部字幕条**（最稳的版式）
- 底部一条向上渐隐的暗带（`Band`）；左下一个书法大字的小标题，右侧一根金色竖线（`BigC`）；竖线右边是宋体、疏排的关键词，同屏最多两行（`KeyC`）；更细的说明用一行小字（`NoteC`）。
- 标题随这一页不变，关键词随每一拍换（`ClearWords`）。字都是原生文本框。
- 为什么是它：字直接压在亮画面上、位置不固定会显得乱；字幕条让画面归画面、字归字。

**图表一次一张，大，没有框**
- 曲线一条条画出来，末端带名字；要强调的地方用红色虚线和小箭头。图表后面垫一块柔边的局部压暗，不加边框。

**无框对照表**
- 几行细线分隔，左右两列对照，中间一列小字是比较项。压在暗带上。

**贴在场景旁的大字**
- 开场的书法大字不排整齐，贴着各自的场景，大小和角度各不相同。

**小签与角标**
- 小签：一段色条加一个黑体词，用在分屏的角上（`Tag`）。
- 角标：右上角一个随镜头换的层级名（逐级拉远时用）。

**结论句**
- 画面压暗，一行宋体疏排的大字加一根短金线，下面一行小字。同时把角上的小标题收掉。

## 8. 收尾

**山路上的车流**
- 画面：拂晓的大山谷，一条盘山路上车队首尾相接，车灯沿路一节一节往上流动，远处雪山被第一缕阳光照成金色。
- 做法：一张图，循环动图里只让暖色的灯沿着路的方向做流动的明暗。
- 反响：对方几次都要求保留这张；后来改的"云雾拨开"版本被要求换回它。

**只剩一点光**
- 画面：整幅画慢慢暗下去，最后只剩一个点（珍珠、灯、窗）的光，再淡出。
- 做法：压暗层淡入，保留的光点是一张小的柔光图层，最后单独淡出。

## 9. 做过但被否的

知道为什么不行，比知道怎么做更省事。

| 做法 | 为什么被否 |
|---|---|
| 震动、闪白、冲击模糊、速度线 | 低级 |
| 电影字幕式的阶段进度条、自创的装饰组件 | 没人要的文字和界面元素 |
| 抽象数据空间、全息、发光数据线 | 至少一半画面得是真实场景 |
| 一幕一张图加一个循环动作 | 单调、空、不宏伟 |
| 横穿画面的抽象示意线 | 丑，太抽象，要更写实 |
| 结尾的总结三联画、三个词收尾 | 套路 |
| 页与页之间同一个场景换个光 | 算复用素材 |
| 和内容无关的开场加硬切 | 关联度不强，转场僵硬 |
| 字直接压在亮画面上、位置不固定 | 乱 |
| 电影调色的生成图（青橙、光晕、体积光） | AI 感强 |
| 很真实但要点不突出的画面 | 没突出要点 |
| 深色主题界面加界面内推近 | 房间已经暗了，界面不要再黑；界面自己不要运镜 |
| 界面浮在画面上挡住人头 | 太假 |
| 一整条叙事动图放在点击之后 | 技术上不成立，动图从进页就开始走，见 `pitfalls.md` |

## 10. 参考来源清单

找画面时翻过的地方，供下次发散时接着往外找，不限于这些。

- **时间流逝**：《少年时代》《诺丁山》四季长镜头、《飞屋环游记》开头、定点摄影。
- **重来和回放**：《罗拉快跑》《萨利机长》。
- **卷宗和证据**：《黑水》《聚焦》《天才捕手》、博物馆里失窃后留着的空画框。
- **指挥与会商**：《阿波罗 13 号》《萨利机长》、单场景戏。
- **计划推演**：劫案片的方案讲解段落、战争片的作战地图。
- **剪辑手法**：匹配剪辑、一点透视、越肩镜头、插入特写。
- **信息设计**：小型趋势线、台风路径的不确定性圆锥、校样上的红笔、博物馆标签式的引线标注、俯拍平铺。
- **展陈**：美术馆的墙色、画框灯、展签；作品墙。
- **摄影**：通讯社的现场纪实、无人机航拍、高感光度夜拍、静物摄影。
- **领域里真实存在的物件**：设备和围栏、密集架档案室、印章和印泥、控制室和值班室、交接班记录本、路障、颜料和原料。这类东西比任何比喻都可信。
