# 字体与版式：别让一页看起来像 AI 做的

字是一页里最先被看见、也最先暴露"这是模板"的东西。这份文档写的是选字、排字的办法，以及一套在中国画、历史、红色题材上做过并被认可的中式版式。字体文件和代码在 `scripts/typo.py`、`scripts/specimen.py`、`scripts/pptkit.py`。

## 1. 什么样子会被认出是 AI 做的

一份课堂 PPT 的样张被评价为"很像 AI 经常能做出来的 PPT，因为这种字体风格、处理方式都很像"，同一个人之前另一份 AI 做的稿子也是同一种感觉。那套样子是：

- 暗底，加一根金色细线；
- 宽字距的思源宋体或 Noto Serif 做标题，再配一行宽字距的副题；
- 一个细体的阿拉伯数字年份（"1959"）做大字，旁边一根竖线、两行说明；
- 左下角固定一条字幕带，每页一样。

每一样单看都不难看，凑在一起就是"默认答案"。它适合答辩、路演这类讲技术的稿子（底部字幕条在那里是被选过、被认可的，见 `style-library.md`），放到讲一幅画、一段历史的稿子上，就显得空和套路。

**规则：** 题材有自己的文化气质时，字体和版式从题材里来，不用默认那一套。开工前先想"这个题材在真实世界里，字是怎么出现的"：古画上是题跋和印章，古籍是竖排、乌丝栏、刻本字，老报纸是铅字和栏线，展馆是展签。

## 2. 先找字，再看样

1. **去下载，不要只用系统里有的。** 系统自带的宋体、楷体、微软雅黑一眼就是 Office。几个可靠的来源：
   - `github.com/wordshub/free-font`：免费中文字体合集，有演示系列（秋鸿楷、夏行楷、春风楷、悠然小楷）、令东齐伋体、江西拙楷、王汉宗系列（魏碑、行书、隶书）、全字库说文解字（篆书）、刻石录系列等，可以直接从 raw 地址按文件下载。
   - `github.com/TrionesType/zhuque`：朱雀仿宋，古籍刻本味的仿宋，适合说明小字。
   - `github.com/Warren2060/ChillCalligraphy`：寒蝉书体（春秋、龙藏楷），瘦劲的书法楷，适合诗句。
   - `github.com/InkPantherType/LiyuShoushu`：李裕手书。
   - Google Fonts：Ma Shan Zheng、Zhi Mang Xing、Long Cang、Liu Jian Mao Cao（手写和草书）。
   - 本机已装的"演示镇魂行楷""演示流云楷"这类演示字体也可以用。

   用之前看各自的授权说明。
2. **拼一张字样表一起比。** `python scripts/specimen.py out.jpg 字体目录 --title 标题 --line 一句诗`，每款字一格，同样的标题和诗句，暗底。十几二十款放在一起，好坏一眼就分出来。
3. **查缺字。** 书法字体、篆书字体常缺简体字或生僻字，缺的字会被系统换成别的字体，混在一行里很难看。字样表会把缺字标红；代码里用 `typo.missing_glyphs(字体, 文本)`。实测：说文篆书缺"娇、雪、晴、红、峰、渊、关、园"等简体字，印章里改用繁体（嬌、紅、關、淵）或换成魏碑字体。
4. **看简繁字形。** 有些字库号称有简体，其实是繁体或日本字形的变体（汇文明朝体的"讲、说、红"就不对）。正文小字一定渲染一行常用字看一眼。
5. **先出样张给对方挑字，再全量做。** 字定下来以后，所有页面都按这套来。

## 3. 一套中式版式（《江山如此多娇》课堂稿实际用的）

| 用途 | 字体 | 做法 |
|---|---|---|
| 页面关键词、单个大字 | 演示镇魂行楷（干笔行楷） | 一页一个，很大：雪、晴、朱砂、俱往矣、风雪 → 晴日。竖排或单字，擦除自上而下"写"出来 |
| 诗句、副题 | 寒蝉春秋体（瘦劲书法楷） | 竖排，从右往左读，列与列之间画乌丝栏（细竖线，透明度 50%） |
| 说明、年份、出处 | 朱雀仿宋 | 小字，竖排贴在大字旁边，年份用汉字数字（一九五九年），不用阿拉伯数字大字 |
| 印章 | 说文篆书 / 魏碑 | 朱文印（红字红框）压在标题末尾，白文名章（红底白字）放在讲解人名字前；缩放进入，像盖下去 |
| 强调色 | 朱砂红 | 全稿只有这一种强调色，和题材里的红（画上的太阳、朱砂、红旗）是同一个红 |

几条排字的经验：

- **竖排是这类题材最有效的一招。** 一列字从上往下擦除出现，本身就是"写字"的动作，比任何飞入都有分寸。
- **字的颜色跟着底走。** 暗画面上用暖白（不是纯白）；亮的纸、墙、画面上直接用深墨色，不加投影，像写在上面。
- **一页只有一个主角字。** 大字、诗句、说明三级，大字最多三四个字。
- **字贴着画面里的东西放。** 空墙上写命题、画框旁边写原话、展签式的引线标注，比固定的字幕区更像这个场景的一部分。
- **画上本来有字（题跋、手迹）时，用它，不要盖住它。** 原作的题字、手稿本身就是最好的字：切成逐列的图层让它一列列出现，比打一行字更有分量。

## 4. PowerPoint 里的坑

- **竖排文本框要用方向 4**（`msoTextOrientationVerticalFarEast`），列从右往左。方向 5 的列是从左往右排的，两列以上的中文读序会反。
- **横排文本框关掉自动换行后，宽度会塌成十几磅**，居中、右对齐全部失效，字会偏到左边。要居中就开自动换行、给足宽度。`pptkit.Kit.text` 已经按这两条写好。
- **新装的字体当前会话认不到。** 装到用户字体目录、写注册表之后，再调一次 `AddFontResource` 并广播 `WM_FONTCHANGE`，PowerPoint 才能马上用；否则要重开 PowerPoint。
- **放映的电脑要装同样的字体。** 交付时附一个"字体"文件夹，说明换电脑先装字体。嵌入字体对大的中文字库不可靠，也会让文件很大。
- **PowerPoint 里的字体名是字库的家族名，不是文件名。** 寒蝉春秋体在 PPT 里叫 `ChillCalligraphyChunQiu`，朱雀仿宋叫 `Zhuque Fangsong (technical preview)`。用 fontTools 读 name 表的 nameID 1。
