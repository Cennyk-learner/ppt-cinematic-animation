# 怎么发散

这里只给找画面的方法和提案的写法，不给答案。`style-library.md` 里的东西是做过的，新题目请先自己想，再去对照。库里没有的画面才最值得做。

## 从内容里找画面

1. **把这一页要讲的事写成因果句。** 不写"历史数据优势"这种标签，写"每换一次设备，以前的记录就断了，所以看不出长期趋势；我们的不会断"。因果句里的名词和动词就是画面的原料。
2. **问这件事在真实世界里长什么样。** 它发生在哪个房间、哪片海岸、哪面墙上？留下了什么看得见的痕迹？领域里真实存在的物件（设备、文件、颜料、路障、画框）比任何比喻都可信，也最容易做到"至少一半是真实场景"。
3. **问它是哪一种结构。** 时间流逝、前后对照、缺席和丢失、粗放和精确、分散和汇聚、计划和执行、整体和细节。每种结构在电影和设计里都有人解决过，去想谁拍过、谁画过。
4. **问光从哪来。** 这一幕里谁在发光、照亮了什么、什么时候亮起或熄灭。说不出光从哪来的画面，多半会平。
5. **问有没有至少两种不同的动作。** 一幕只有一个循环动作会显得单调。
6. **问去掉字还看不看得懂。** 看不懂就是画面没在讲事，字再多也救不了。
7. **先把手头的材料用一遍。** 原稿、对方给的照片、系统界面、数据，先看完、点完。最有用的画面常常藏在材料里：一个系统页面真的点一遍，可能发现它自带一段"告警、生成报告"的流程，正好是这一页要讲的事。

## 往外找参考

别只在一种片子里找。几个方向都翻一翻：故事片的镜头语言和剪辑手法，纪录片和新闻摄影的质感，信息设计里表达不确定性、对照、时间的办法，博物馆和展览的陈列方式，还有题材所在领域自己的图像传统。参考要具体到"哪部片子的哪一场戏"或"哪种图的哪个做法"，这样对方有画面感。

## 提案怎么写

出三到四个方向，彼此在类型上不同，而不是同一个想法的三个变体。每个方向写四样东西：

- 一句话的画面。
- 参考了什么。
- 观众依次看到什么（三四条，每条一句）。
- 好处和代价各一句。代价要说真话：新素材多、字多要凑近看、是示意而不是真实界面、气势弱。

然后给出你的推荐和推荐的组合，并把需要对方定的事编号列出来。提案阶段不动手做成品；对方选定方向后先出一两张样张。

如果对方要求"都做一遍"，把方向拼成几个完整的版本（每个版本都要把这一页该讲的事讲全），能共用的场景共用，最后给一张各版本关键帧并排的对比图。

## 一个走过的例子：讲一幅画的课堂 PPT

题目：艺术鉴赏课，讲维米尔的《戴珍珠耳环的少女》，录屏讲解，十几页。要求不要 AI 感、动画越好看越好、页面只放关键词。

**先定整体风格。** 出了三种缩略图让对方挑：A 展厅（墨绿锦缎墙、金色画框、黑色展签），B 暗室与光（近黑的底，画是唯一的光源），C 颜料与画册（纸、颜料、印刷品的质感）。对方选了"A 开场 + B 正文"：开头像走进美术馆，进了正文就只剩画和光。

**再按每页的因果句找画面。** 几个例子：

| 这一页要讲的事 | 画面 | 结构 |
|---|---|---|
| 维米尔的画里，光总是从左边的窗户照进来；这幅没有窗，光还是从左边来 | 画先是全暗的，一块软边的暗层从左往右退开，像光从左边照进来；再用三个小圈加引线点出受光的地方 | 光从哪来 |
| 头巾的蓝是群青，原料青金石比黄金还贵 | 平滑切换推近到头巾，再叠化到一块青金石原石、研钵和蓝色颜料粉的静物 | 整体 → 细节 → 实物 |
| 那颗珍珠其实只是两笔颜料 | 推近到珍珠的极近特写，看得见笔触和裂纹；引线标出"一笔厚涂的高光、一抹衣领的反光" | 整体和细节 |
| 他一生只留下三十几幅画 | 三十几幅作品错落着一张张淡入，铺满一面墙；然后全部压暗，只留她 | 分散和汇聚 |
| 画家生活在代尔夫特 | 一张老地图缓缓推近，叠化成他画的《代尔夫特一景》 | 匹配剪辑 |
| 结尾 | 画慢慢暗下去，最后只剩珍珠那一点光 | 光的熄灭 |

几件值得记住的事：第一，"光从左边来"这一页本来可以写成一段文字，变成画面以后，观众自己就看到了。第二，每一页的动作类型都不一样（推近、叠化、擦除、错落淡入、遮罩退开），整份稿看下来不疲劳。第三，结尾那一点珍珠的光，是从内容里长出来的收尾，比"谢谢观看"四个大字有分量。
